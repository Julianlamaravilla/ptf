# Proyectos Destacados

## Proyecto 1: Adkio

### 🎯 Descripción
Orquestador inteligente de Anuncios. Convierte lenguaje natural en campañas publicitarias automáticamente para particulares o empresas.

**Caso de Uso:** Empresas y emprendedores pueden describir el producto/servicio en lenguaje natural, y Adkio genera automáticamente campañas publicitarias optimizadas.

### 📊 Tipo de Problema Resuelto
- **Categoría:** Problemas Agénticos + Necesidad Directa de Empresas
- **Impacto:** Automatiza la creación de campañas publicitarias, ahorrando tiempo y dinero a empresas

### 💻 Stack Tecnológico
**Backend:**
- Python (FastAPI)

**Frontend:**
- JavaScript (React.js)
- TypeScript
- Vite
- Tailwind CSS

**Infraestructura y Servicios:**
- Supabase (Base de datos)
- Railway (Deployment)
- Docker (Containerización)
- LiteLLM (Abstracción de LLMs)
- **Anthropic Models** (Core del Agente IA)

### 🤖 Características Técnicas Principales
- **Motor de IA:** Agentes de Anthropic
- **Flujo:** Procesa lenguaje natural → Genera estructura de campaña → Crea contenido publicitario
- **Arquitectura:** API REST con FastAPI + Frontend reactivo con React
